ТЕМП iOS v7 — точечная сборка ТОЛЬКО мобильной оболочки, на основе работающей iOS v6.

СДЕЛАНО:
- Убрана отдельная верхняя шестерёнка настроек и скрыта пустая навигационная панель.
- В существующем веб-разделе «Ещё → Настройки» на iPhone появляется кнопка «Вход и безопасность устройства», открывающая нативное окно Face ID. Старый неработающий выпадающий список режима входа скрыт только внутри iPhone.
- Сохранены без изменения работающие Face ID, экран блокировки, размеры полей, запрет нежелательного масштабирования, навигация и объёмная иконка ракеты.
- Номер iOS-оболочки: 7.0. Веб-версия Cloudflare остаётся 12.68.4.

НЕ СДЕЛАНО / ТРЕБУЕТ ОТДЕЛЬНОЙ ПРОВЕРКИ:
- Push: без APNs, серверного планировщика и подходящей подписи реальные уведомления не будут приходить. В этой безопасной сборке не включено entitlement, которое может сорвать бесплатную подпись.
- После полного закрытия iOS WKWebView сохраняет постоянное хранилище, но веб-сессия Supabase может не восстанавливаться: без анализа веб-авторизации нельзя гарантировать исправление только Swift-кодом. Пароли не записываются открытым текстом.
- Отображение настроек зависит от существующей функции tempOpenSettings1264 в текущей веб-версии; если эта функция отсутствует, кнопку нужно будет подключить отдельно.
- Компиляция на macOS и тест на реальном iPhone в данной среде недоступны.
