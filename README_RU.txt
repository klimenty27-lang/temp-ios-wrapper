ТЕМП iOS 8.0 (build 8) — исходники для GitHub, НЕ готовый IPA.
Основа: работающая iOS Mobile v6.
Обозначение v8 отличает этот пакет от ранее выданных промежуточных v7.

Что изменено:
- Убрана верхняя шестерёнка. В настоящем разделе «Ещё» добавляется пункт «Настройки».
  Работает как с исходной веб-12.68.4, так и с новой 12.70.
- Нативные настройки открываются по нажатию на этот пункт, закрываются «Готово»;
  текущая веб-страница не перерисовывается.
- Запоминается только логин после успешного входа. Есть отключение и «Забыть логин».
- Подготовлены autocomplete=username/current-password для системного автозаполнения.
  Пароль ТЕМП приложение отдельно НЕ хранит. Сохранить/выбрать пароль можно
  в системном менеджере «Пароли». Показ предложения/системная проверка зависит от iOS
  и настроек устройства; автоматическое появление окна «Сохранить пароль» не обещается.
- «О приложении» показывает номер iOS-оболочки и сообщённый веб-частью номер.

Сохранено:
- Тот же Bundle ID kz.temp.app и название «ТЕМП».
- Та же объёмная ракета и launch screen (изображения не перерисовывались).
- Постоянное хранилище WKWebView, Face ID/код устройства, масштабирование, веб-навигация.
- Явный «Выйти» по-прежнему завершает сессию. Смахивание приложения — не выход.
- При возврате из фона окно настроек закрывается перед экраном защиты.

Установка:
1. Сначала можно опубликовать веб-12.70, проверить её.
2. Распаковать этот ZIP; в temp-ios-wrapper заменить папку TempApp и project.yml.
   НЕ удалять репозиторий. .github/workflows/build-ipa.yml НЕ меняем.
   В пути должен быть TempApp/ViewController.swift, а не имя ZIP/TempApp/... .
3. GitHub Actions -> успешная новая сборка -> скачать TEMP.ipa из артефакта.
4. Sideloadly -> выбрать новый IPA, тот же Apple Account и телефон -> установить поверх.
   Удалять работающий ТЕМП с телефона для этого обновления не требуется.
5. Проверить Ещё -> Настройки -> изменить режим -> Готово -> возврат в Ещё;
   повторный запуск; Выйти -> логин сохранён -> пароль вручную/системное автозаполнение.

Важно:
- Это не готовый IPA. Swift прошёл синтаксический разбор, XML/plist/JSON проверены.
- Xcode/macOS и реального iPhone в этой среде нет: компиляция с UIKit,
  Face ID и реальное Password AutoFill ещё не испытаны.
- Push не подключён и в эту контрольную сборку не добавлялся. Предыдущие серверные
  заготовки не меняются. Согласованное расписание 21:00–22:00 не активировано.
- SQL для установки этого пакета не требуется. GPS не добавляется.
