ТЕМП — iOS Mobile v5 (исходники для GitHub/XcodeGen)

На основе iOS Adaptive v4, без изменений базы, Cloudflare и веб-логики.
Сделано:
- Новый значок ТЕМП: бело-оранжевая ракета на тёмно-синем фоне (авторская техническая отрисовка по утверждённому направлению; требуется визуальное согласование).
- Нативный экран блокировки при запуске/возврате приложения, Face ID или код-пароль УСТРОЙСТВА через LocalAuthentication.
- Настройка «без повторной проверки» и выбор защиты в верхней панели.
- Сохранение веб-сессии WKWebView между запусками, без хранения пароля в открытом виде.
- Исправление увеличения поля пароля: размер текста input >= 16px, отключение pinch zoom веб-контента.
- LaunchScreen сохранён и задан в project.yml.

ОГРАНИЧЕНИЯ:
- Режимы «Face ID/код-пароль» и «код-пароль» сейчас используют общий системный механизм iOS; строго принудить только ввод кода отдельным переключателем нельзя без собственной PIN-системы.
- Это защита входа в приложение на уровне устройства, НЕ замена серверной проверки пароля Supabase.
- Push-уведомления ещё НЕ включены: требуется APNs entitlement, подпись, сервер регистрации токенов и отправка; при бесплатной подписи через Sideloadly возможности ограничены.
- Полноценный единый интерфейс настроек и тёмно-сине-оранжевое оформление веб-экранов потребуют отдельного Cloudflare обновления.
- В текущей среде нет Xcode/macOS: IPA не собран, компиляция Swift на реальном iPhone не проверена.

ЗАГРУЗКА:
Распаковать архив. В GitHub temp-ios-wrapper заменить папку TempApp и файл project.yml.
Не трогать .github/workflows/build-ipa.yml. Запустить Actions, скачать IPA, установить через Sideloadly.
Перед установкой сохраните нужные несинхронизированные черновики.
