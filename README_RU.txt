ТЕМП iOS wrapper v1
===================

Что это:
- Настоящая iOS-оболочка на WKWebView.
- Открывает https://temp-kz.pages.dev/
- Использует ту же Supabase-базу, поэтому склад, люди, отчёты и другие данные не копируются в IPA.
- Обычные обновления ТЕМП в Cloudflare появляются внутри приложения без новой сборки IPA.
- IPA собирается в GitHub Actions на облачном macOS и получается НЕПОДПИСАННЫМ.
- Sideloadly подписывает IPA тестовым Apple ID и ставит его на iPhone.

Сборка через GitHub:
1. Создать пустой PUBLIC репозиторий, например temp-ios-wrapper.
2. Загрузить в корень репозитория все файлы и папки из этого архива.
3. Открыть вкладку Actions.
4. Workflow "Build TEMP unsigned IPA" запустится после загрузки. Если нет — открыть его и Run workflow.
5. Дождаться зелёной галочки.
6. Открыть завершённый запуск и скачать Artifact "TEMP-iPhone-IPA".
7. Распаковать загруженный ZIP — внутри будет TEMP.ipa.
8. Перетащить TEMP.ipa в Sideloadly, выбрать iPhone, ввести тестовый Apple ID и нажать Start.

Важно:
- Лучше использовать отдельный бесплатный Apple ID только для тестовой подписи, а не основной iCloud.
- Бесплатная подпись Apple действует 7 дней, потом IPA нужно подписать/установить снова.
- Рабочие данные ТЕМП при этом остаются в Supabase и не пропадают.
